# Prompt para continuar IMPULSATECH en Google Antigravity

Quiero que actues como un Senior Full-Stack Developer + Senior UI/UX Designer.

Este repositorio contiene una landing page para mi negocio **IMPULSATECH**, desarrollado con Next.js + React + TypeScript + CSS nativo. Ya existe una primera version funcional. NO empieces de cero y NO reemplaces arbitrariamente el diseño actual: primero revisa todos los archivos y ejecuta el proyecto.

## Contexto del negocio

IMPULSATECH ofrece soluciones digitales para negocios: tarjetas NFC y QR para reseñas de Google, landing pages y webs, WhatsApp Business, automatizaciones, chatbots y agentes de IA.

## Referencia visual

Busco una experiencia premium inspirada en una landing de reparacion de celulares que usa:
- hero oscuro y muy visual;
- mensajes que cambian;
- formulario/configurador por pasos;
- tarjetas de servicios;
- seccion oscura con visual por capas;
- proceso de 4 pasos;
- casos reales;
- CTA final.

La referencia es solo para estructura, ritmo, jerarquia y calidad visual. No copies marca, textos, imagenes ni activos de terceros.

## Objetivo

Mejora progresivamente la landing existente hasta que tenga calidad de produccion. Prioriza:
1. Responsive perfecto en desktop, tablet e iPhone.
2. Animaciones suaves, sobrias y con buen rendimiento.
3. Accesibilidad, SEO y Core Web Vitals.
4. Conversión: CTA claros y contacto por WhatsApp.
5. Componentes mantenibles y datos faciles de editar.
6. No inventes metricas, testimonios, clientes o resultados.

## Secciones deseadas

- Header sticky.
- Hero: "Haz que tu negocio se vea. Y se elija."
- Servicios: NFC + QR, Landing/Web, WhatsApp, Automatizaciones, Agentes IA.
- Configurador: tipo de negocio + objetivo + recomendacion.
- Seccion "Lo que no se ve. Cambia todo."
- Cómo funciona en 4 pasos.
- Casos reales: Pastelarte Coffee Cat, Polleria Misky y hospedaje (usar placeholders visuales hasta recibir fotos reales).
- Formulario/WhatsApp.
- Footer.

## Forma de trabajo

1. Inspecciona el proyecto.
2. Ejecuta `npm install` y `npm run dev`.
3. Abre la pagina en el navegador y revisa desktop y mobile.
4. Antes de cambios grandes, resume brevemente el plan.
5. Implementa en iteraciones pequeñas.
6. Despues de cada iteracion, verifica visualmente y corrige errores de consola.
7. No agregues dependencias innecesarias.
8. Conserva la identidad IMPULSATECH.

Cuando necesites datos reales (WhatsApp, dominio, fotos, redes, precios o logo final), deja un placeholder claramente marcado y dime exactamente que informacion falta.
