# IMPULSATECH Landing Page

Landing page premium inspirada en la estructura y sensación visual de la referencia compartida, pero con identidad, contenido y componentes propios para IMPULSATECH.

## Requisitos

- Node.js 20.9 o superior (recomendado: Node 22 LTS)
- npm

## Ejecutar localmente

```bash
npm install
npm run dev
```

Luego abre `http://localhost:3000`.

## Build de producción

```bash
npm run build
npm start
```

## Personalizaciones pendientes antes de publicar

1. Reemplazar los mockups de casos reales por fotos reales.
2. Conectar el formulario a WhatsApp, correo, Formspree, Resend o CRM.
3. Agregar número de WhatsApp. Las redes sociales oficiales ya están enlazadas en el footer.
4. Agregar dominio final, favicon/logo definitivo y metadata social.
5. Si se desea, agregar Analytics y pixel de Meta.

## Stack

- Next.js 16.4
- React 19.3
- TypeScript
- CSS nativo (sin librería visual externa)
